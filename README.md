# 길수매매법 코인 검색기 v0.8.2

이번 버전은 **손절이 너무 잦은 후보를 실전에서 더 강하게 거르는 보수화 패치**입니다.

## 핵심 변경
- 업비트 KRW 마켓 전용
- 롱 전용
- 손절/익절 퍼센트 우선 출력
- 너무 얕은 손절폭 후보 제거 강화
- 멀티타임프레임 확인 없는 후보 제거
- 마지막 1시간봉 진입 확인봉 조건 추가

## v0.8.2 반영 내용
- 메인 실전 필터 강화: 최소 손절폭 1.2%, TP1 3.0%, TP2 5.0%, RR 2.0
- 서브 실전 필터 강화: 최소 손절폭 1.0%, TP1 2.4%, TP2 4.5%, RR 1.8
- 30분봉/4시간봉 확인이 전혀 없는 후보는 제외
- 마지막 1시간봉에서 종가 위치/양봉/RSI 상승 확인이 약하면 제외
- 워치리스트 기준도 함께 상향해서 애매한 후보 유입 축소

## 해석
이 버전은 신호 개수를 늘리는 버전이 아니라 **손절 유발 가능성이 높은 어설픈 진입 후보를 줄이는 버전**입니다.
결과는 줄어들 수 있지만, 통과 종목의 질은 더 보수적으로 관리됩니다.
